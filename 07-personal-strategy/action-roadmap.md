## 一、核心结论

康波研究对个人唯一有价值的问题不是"哪年见底"，而是：**在不确定的 5–10 年里，如何不爆仓、不失能、不失去选择权。**

本文件把个人应对拆成三层：**财务 → 能力 → 家庭**。优先级固定，不可颠倒。

**关键修正（相对 v0.1）**：
- 删除"2028–2030 进入第六轮回升"这类年份结论，改为情景条件；
- 资产配置比例改为"示意框架"，必须经 `investment` 仓库的压力测试才能执行；
- 职业方向从"学 AI 工具"细化为"哪类能力仍能产生经济价值"。

- 置信度：中高（就"降杠杆、留现金、可迁移"这些原则）；低（就具体时点）。

## 四、关键数据

### 4.1 财务阈值（参考值，非标准）

| 指标 | 建议阈值 | 理由 | 备注 |
|---|---|---|---|
| 房贷月供 / 家庭税后月收入 | ≤ 35% | 失业 6 个月仍可负担 | 收入不稳定者应更低 |
| 总负债 / 年税后收入 | ≤ 3 倍 | 超过即进入利率敏感区 | 含所有负债 |
| 现金 + 类现金 / 月支出 | **9–12 个月（目标）**；**6 个月（硬底线）** | 覆盖一次完整失业周期 | 6 个月以下为警戒区，见 `06-investment/risk-management.md` §四 |
| 高息负债 | 清零 | 利率上行的第一波冲击 | 无例外 |
| 单一资产占总资产 | ≤ 50% | 集中度风险 | 房产尤其 |

### 4.2 三层优先级

```
第一层：财务生存  ← 先做，且必须做完
第二层：能力迁移  ← 与第一层并行
第三层：家庭韧性  ← 贯穿始终
```

**不可颠倒的原因**：能力迁移需要时间（6–24 个月），而财务爆仓可以在一周内发生。两者的时间尺度不同，因此顺序不可互换。

## 五、历史案例

- **1930s**：有稳定现金流与低杠杆的家庭，在萧条中损失有限；而 1929 前加杠杆买股票的中产，是最先崩塌的群体。
- **1970s**：持有名义资产（存款、债券）的人被通胀吞掉；持有实物与生产性资产的人受损较小。
- **不相似点**：当代社会保障与央行工具远强于 1930s，但债务水平也远高。**缓冲更强，脆弱性也更高。**

## 六、当前判断

### 6.1 财务层

- 先算清三张表：现金流量表、资产负债表、风险敞口表（币种 / 行业 / 地域 / 期限）。
- 优先还高息债，优先建现金跑道，**不借新钱去赌新周期**。
- 不把房产净值当可支出财富。

### 6.2 能力层（技术从业者专项）

> 本仓库只做方向判断。具体学习路径与项目实践归 `investment` 之外的职业计划管理，此处只回答"哪类能力仍能产生经济价值"。

| 方向 | 经济价值判断 | 理由 |
|---|---|---|
| **AI Agent 工程**（工具调用、多步任务、状态管理） | **高，且稀缺** | 需要理解业务边界与失败处理，不是调 API |
| **企业级 AI 应用落地**（流程嵌入、权限、审计） | **高** | 组织重构能力稀缺，是 TFP 兑现的真实瓶颈 |
| **RAG / 知识库 / 数据治理** | **高中** | 数据质量是上限；但单纯"搭 RAG"会商品化 |
| **业务流程自动化**（与 ERP / MES / 工单系统集成） | **高** | 与具体行业绑定，替代难度高 |
| **AI 产品化与变现**（定价、留存、单位经济） | **高但风险大** | 需要商业能力，失败率高 |
| **单纯调用大模型 API** | **低** | 会迅速商品化，议价能力接近零 |

**判断标准（可自检）**：能否在 90 天内，用新工具把某个具体环节的效率提升 30% 以上，并留下**可验证的记录**（数据、案例、作品）。能，说明已跨过门槛。

**"老本行 × 新工具"矩阵（示例）**

| 老本行 | × 新工具 | 产物 |
|---|---|---|
| Java 后端 | Agent 编排 + 工具调用 | 可交付的企业智能体系统 |
| 财务 | 数据 + AI 辅助 | 预测模型 + 合规自动化 |
| 外贸 / 供应链 | 多语言模型 + 跨境合规 | "产品 + 服务 + 金融"复合出海 |
| 制造 / 班组长 | 机器人排产 + MES | 管设备、看良率、调参数的现场工程师 |
| 法律 / 审计 | 合同大模型 + 知识库 | 标准化审查 + 复杂判断 |
| 医疗 / 影像 | 辅助诊断 + 数据 | 人机协同的临床决策 |

### 6.3 家庭层

- 现金储备维持在可承受收入中断的水平。
- 不靠借贷扩大投资规模。
- 避免收入来源过度集中（但注意：**三个靠流量的副业，本质是一个风险源**）。
- 保持职业技能可迁移性。
- **写下**最坏情况的现金流预案（谁先失业、房贷如何过渡、老人医疗如何托底），全家知道。

## 八、结论失效条件

1. 若出现明确的"技术驱动复苏"强信号（TFP 连续回升 + 中位工资上行）→ 现金比例可下调，进攻层可增加，本文件需修订。
2. 若出现系统性危机 → 现金与降杠杆优先级进一步提高，资产配置示例全部作废。
3. 若个人收入结构发生重大变化（换行业 / 失业 / 创业）→ 阈值需全部重算。
