# 下一次康波：应对手册

> 配套文件：《过去五次康波梳理.md》
> 适用对象：普通家庭、技术从业者、小企业主——不是机构，不是基金经理。
> 核心立场：**不预测拐点，只管理暴露。** 康波能告诉你“冬天有多长、账单怎么结”，不能告诉你“哪天开盘反转”。

---

## 一 先把话说清楚：这份手册管什么，不管什么

**管**：
- 如何在 5–10 年的高不确定性里，不被杠杆、职业枯竭、单一资产、健康风险一次性击穿；
- 如何在“旧行业退潮、新行业招人但要求跨代技能”的错位期，保住收入并换到新赛道；
- 如何用最小成本，把家庭资产负债表做到“能活过 2028–2032”。

**不管**：
- 不荐股、不推具体基金、不预测房价涨跌、不预测金价顶点；
- 不假设“AI 一定是第六轮主导技术”（历史上被寄予厚望却未兑现的通用技术不止一次）；
- 不假设“这次一定更温和”（也可能更剧烈，见第三节三情景）。

---

## 二 判断当前坐标：四个可自行核验的信号

不要看新闻标题，看这四个**结构性信号**。每季度看一次即可。

| 信号 | 看什么 | 含义 |
|---|---|---|
| **① 生产率** | 全要素生产率（TFP）增速是否出现趋势性回升 | 未回升 = 新技术还在“资本开支期”，未进入“生产率兑现期” |
| **② 债务** | 政府 / 企业 / 居民三部门杠杆率是否还在上行 | 还在上行 = 出清被推迟，风险在累积而非释放 |
| **③ 信用** | 高收益债利差、中小银行兼并、地方平台重组频率 | 利差走阔 + 兼并增多 = 出清从“阴跌”转向“局部爆破” |
| **④ 分配** | 青年失业率、生育率、基尼系数、民粹／保护主义政策强度 | 恶化 = 制度重构压力上升，战争风险溢价上升 |

**经验法则**：
- ①未起 + ②③④恶化 → **冬中**：防守为主，不扩张；
- ①开始起 + ②③仍在恶化 → **冬末春初**：最难受但机会最多，逐步建仓能力与资产；
- ①起 + ②③改善 → **春**：可以加杠杆，但要慢。

**散户最常犯的错**：把“④恶化”解读为“要完了”，把“①局部起”解读为“春来了”。两者都超前或滞后 2–4 年。

## 三 三情景：不管哪种，你的动作都有交集

| 情景 | 触发条件 | 大致形态 | 持续时间 |
|---|---|---|---|
| **A 软着陆切换** | 通胀回落、AI 资本开支转为收入、地产拖累收窄 | 2028–2030 进入第六轮回升，慢牛 | 3–5 年过渡 |
| **B 二次探底** | AI 资本开支退潮 + 商业地产／信用事件 + 高利率维持 | 再杀一轮估值，杀完是十年筹码 | 2–3 年 |
| **C 技术证伪／长期滞胀** | 大模型 ROI 无法兑现、能源与电网瓶颈、贸易壁垒 | 第六轮推迟到 2035 后，长滞胀 | 5–10 年 |
| **D 地缘黑天鹅** | 台海／中东／关键矿产与算力禁令升级 | 秩序重构，出清方式转向“非经济手段” | 不确定 |

**关键洞察**：四种情景下，**“降杠杆 + 保留现金跑道 + 复合技能 + 分散地域与币种”这四个动作都是对的**。所以不必等看清情景再行动——**先做这四件，再用剩下的钱去赌方向**。

## 四 五道防线（按优先级排序，越靠前越救命）

### 防线 1：家庭资产负债表（最高优先级）

历史上每一轮萧条，**先死的是杠杆，后死的是行业**。

**硬指标（建议值，按自身情况调整）**：

| 指标 | 建议阈值 | 理由 |
|---|---|---|
| 房贷月供 / 家庭税后月收入 | **≤ 35%** | 失业 6 个月仍能扛住 |
| 总负债 / 年税后收入 | **≤ 3 倍** | 超过即进入“利率敏感区” |
| 现金 + 类现金 / 月支出 | **≥ 9–12 个月** | 覆盖一次完整失业周期 |
| 高息负债（信用卡、消费贷、网贷） | **清零** | 任何利率上行的第一波冲击 |
| 单一资产占总资产 | **≤ 50%** | 尤其房产 |

**必做动作**：
1. **不借新钱去赌“新周期”**。萧条期加杠杆，是历史上最普遍的致死方式。
2. **不把房产净值当成可支出财富**。房价是账面，现金流才是真的。
3. **优先还高息债，而不是优先追求高收益**。还 15% 的债 = 无风险赚 15%。
4. **保留“可撤离性”**：至少一个账户在境外或有外汇计价资产（合规前提下），用于对冲单一货币风险。

### 防线 2：收入结构（第二优先级）

**核心原则：萧条期，收入比资产重要；多元收入比高薪重要。**

- **主业的“抗萧条性”打分**：需求是否刚性（医疗、能源、食品、维修、教育、公共安全）？是否依赖可选消费？是否依赖单一客户／单一平台？
- **副线要能“接住”主业风险**：不是送外卖，而是**同一能力在不同行业的第二种变现方式**（如：工程师 → 行业顾问 / 培训 / 小工具产品）。
- **避免“伪多元”**：三个都是靠流量的副业，本质是一个风险源。

### 防线 3：技能复合（第三优先级）

历史规律：**萧条期不淘汰“老行业的人”，淘汰“只会一种工具的人”。**

按“老本行 × 新工具”的公式配置自己：

| 老本行 | × 新工具 | 产物 |
|---|---|---|
| 财务／会计 | 数据 + AI 辅助 | 能做预测模型与合规自动化的财务 |
| 外贸／供应链 | 多语言模型 + 跨境合规 | 能做“产品 + 服务 + 金融”复合出海的操盘手 |
| 制造／班组长 | 机器人排产 + MES | 管设备、看良率、调参数的现场工程师 |
| 法律／审计 | 合同大模型 + 知识库 | 做标准化审查 + 复杂判断的复合人 |
| 医疗／影像 | 辅助诊断 + 数据 | 会用人机协同的临床决策者 |
| 教育／培训 | 自适应学习 + 评估 | 能设计“学习路径”而不只是讲课 |

**判断标准**：你能否在**90 天内**，用新工具把某个具体环节的效率提升 30% 以上，并留下可验证的记录（案例、数据、作品）。能，就说明你已跨过门槛。

### 防线 4：资产配置（第四优先级）

**原则：先防守，再进攻；先不亏，再求赚。**

参考框架（非投资建议，按风险承受力调整）：

```
50% 防守层
  ├─ 现金 / 货币基金 / 短久期国债（6–12 个月支出 + 缓冲）
  ├─ 高等级债券 / 政策性金融债
  └─ 黄金（5–15%）：对冲主权信用风险与地缘风险，不是对冲通胀

30% 实物与资源层
  ├─ 核心城市有真实租金现金流的房产（不是远郊、不是商办）
  ├─ 能源、电力、铜等“新基建金属”相关的低成本指数或实物
  └─ 与自身职业相关的生产性资产（设备、工具、产能）

20% 进攻层
  ├─ 新质生产力（AI、半导体、储能、电网、机器人、创新药）
  ├─ 用指数 / 组合，不押单票
  └─ 定投优于追高；分 24–36 个月建仓
```

**必避清单**：
- 远郊／文旅／商办地产（现金流为负，流动性最差）；
- 高息理财、非标固收、“保本高收益”；
- 没有收入模型的概念公司；
- 任何“三个月翻倍”的课程与社群；
- **在萧条期用经营贷／消费贷去投资**。

### 防线 5：身体与家庭（最低估，但最重要）

历史数据里最容易被忽略的一条：**萧条期的死亡，很大一部分不是"经济死亡"，是"健康死亡"。**

- 失业 → 医保断缴 → 慢病失控 → 家庭崩溃，这是链条，不是偶然。
- 1918 大流感的教训：**公共卫生能力本身就是一种资产**。今天的等价物是：体检、疫苗、慢病管理、心理健康。
- 家庭层面：明确“最坏情况下的现金流预案”（谁先失业、房贷如何过渡、老人医疗如何托底），**写下来，全家知道**。

## 五 时间表：未来 3 年做什么

### 现在（0–6 个月）：清理与准备

- [ ] 算清家庭三张表：现金流量表、资产负债表、风险敞口表（负债币种、行业集中度、地域集中度）
- [ ] 清零高息负债
- [ ] 建好 9–12 个月现金跑道
- [ ] 给主业的“抗萧条性”打分，识别最大单一风险
- [ ] 选定一个“老本行 × 新工具”的组合，制定 90 天验证计划
- [ ] 完成一次全面体检，家庭医疗预案落地

### 6–18 个月：能力与新收入

- [ ] 90 天验证第一轮，产出可展示的成果
- [ ] 用成果换到**第二份收入**（哪怕很小），验证“能力可迁移”
- [ ] 建立信息源：只看结构性信号（第二节四个），不看情绪化内容
- [ ] 开始小额定投进攻层（总资产 5–10%），建立纪律而非追求收益

### 18–36 个月：切换与加仓

- [ ] 若信号 ① 开始起、②③仍在恶化 → 这是“冬末”，**加大能力投入而非资产投入**
- [ ] 若信号 ①②③④ 同时改善 → 才是加杠杆的时点（历史上这样的窗口很短）
- [ ] 若出现情景 D（地缘冲击）→ **第一反应是降杠杆，不是抄底**

## 六 十条反直觉的判断

1. **“这次不一样”在繁荣期是对的，在萧条期是错的。** 萧条期说“这次不一样”的人，通常是在为不肯降杠杆找理由。
2. **现金在萧条期不是垃圾，是期权。** 它买的不是收益，是“别人被迫卖出时你能买”的权利。
3. **最危险的不是失业，是“失业 + 高负债 + 单一技能”三件套同时出现。**
4. **不要等“确认底部”再行动。** 底部只有事后才确认；要做的是“底部来了也死不了”的结构。
5. **新技术最先惠及的不是使用者，是卖铲子的和资本所有者。** 普通人要么进“卖铲子”的链条，要么等应用层降价。
6. **萧条期最好的投资标的是“自己的可迁移能力”**，因为它不随市场定价，且复利不中断。
7. **“稳定”在萧条期是昂贵的。** 追求绝对稳定（体制内、大厂永久岗）的人，往往在裁员时的议价能力最弱。
8. **不要和周期对抗，要利用周期的“错位”。** 别人恐慌抛售技能人才时，是低成本招人与合作的最佳窗口。
9. **健康是唯一不能加杠杆的资产。**
10. **康波告诉你的是“概率分布”，不是“命运”。** 五轮历史里，每一轮都有活下来且活得更好的人——他们共同点是：**低杠杆、多技能、有现金、不站队**。

## 附：本手册的边界

- 本手册基于历史归纳，**不是预测工具**，不构成投资、法律、医疗建议；
- 康波理论在学术上仍有争议（样本仅五轮、技术突破时间不可预测、政策干预会改变周期形态），使用时请把它当作**风险管理的检查清单**，而不是**择时的水晶球**；
- 所有阈值（35%、3 倍、9–12 个月等）为通用参考，请按自身收入稳定性、家庭结构、所在地区调整；
- 涉及重大资产决策、跨境配置、税务与合规事项，请咨询持牌专业人士。
