# 年度归档说明

**所属模块**：08-monitoring / reviews / annual
**版本**：v1.2（新建）
**最后更新**：2026-11-14

---

## 这个目录做什么

年度归档只做一件事：**把已经存在的月度、季度记录汇总成一份可检索的索引与判断复盘**。

命名：每年一份，文件名用年份，年末或次年初写。

**它不替代、不改写、不删除任何原始记录。** 原始记录永久保留在 `monthly/` 与 `quarterly/` 下。V1.1 曾规定「把 30 天前的月度记录按主题归并，删除原始文件」，该条已在 V1.2 废除，理由见 `08-monitoring/data-protocol.md` 第六节。

---

## 归档目录结构

```
08-monitoring/reviews/
├── monthly/            ← 原始月度记录，永久保留，不回改
│   ├── 2026-11.md
│   └── ...
├── quarterly/          ← 原始季度复盘，永久保留，不覆盖
│   ├── 2026-Q4.md
│   └── ...
└── annual/             ← 只写汇总与索引，不存原始记录副本
    ├── README.md       ← 本文件
    └── YYYY.md
```

## 年度汇总应包含的内容

1. **判断命中率回顾**：本年年初（或上年末）明确写下的判断，逐条标注「被证实 / 被推翻 / 仍无法判断 / 因数据不足未验证」。只统计**事前写下**的判断，不得把事后解释算进来。
2. **假设台账变化**：本年新增、升级、降级、推翻的条目编号清单，附对应季度复盘链接。
3. **数据口径与修订事件**：本年发生的统计口径变更、历史序列回溯修订，以及它们是否影响过当时的判断（见 `08-monitoring/data-protocol.md` 第四节）。
4. **指标体系反馈**：长期标「口径缺」的指标、被删除或改名的指标、频率调整记录。
5. **权重与结论变更索引**：指向 `CHANGELOG.md` 的对应条目，不在此重复论证。
6. **流程自评**：月度 / 季度 / 年度流程哪一步做不下去，下一年怎么改。

---

## 明确的禁止项

- 禁止删除或覆盖 `monthly/` / `quarterly/` 下的任何文件。
- 禁止事后修改月度记录中的「当时的第一反应」。
- 禁止把年度汇总写成新的宏观判断——判断写在季度复盘与研究文件里，年度只做索引。
- 禁止在汇总里使用修订后的历史值评价当时的判断而不加说明（前视偏差）。
