# 月度跟踪

**所属模块**：08-monitoring
**版本**：v0.1
**最后更新**：2026-11-09

---

## 用途

月度不做判断，只**记录方向**。目的是防止"事后回忆偏差"——人在季度末回看时，总会以为自己当时就看出了变化。

记录放在 `reviews/monthly/YYYY-MM.md`，一行一个指标，不写分析。

## 格式

```markdown
# YYYY-MM

| 维度 | 指标 | 数值 | 方向 |
|---|---|---|---|
| 技术生产率 | TFP（最新同比） | | ↑/→/↓ |
| 债务信用 | 高收益债利差 | | ↑/→/↓ |
| 货币金融 | 10Y 实际利率 | | ↑/→/↓ |
| 产业资本 | 产能利用率 | | ↑/→/↓ |
| 贸易资源 | 全球贸易量同比 | | ↑/→/↓ |
| 社会人口 | 青年失业率 | | ↑/→/↓ |

## 异常事件
-

## 当时的第一反应（先写下，不要修改）
-
```

**"当时的第一反应"这一栏很重要**：它是后来自查"我到底是看出来的，还是编出来的"的唯一依据。

## 数据来源优先级

1. 一手官方（FRED、BIS、OECD、世界银行、国家统计局、央行、IEA）
2. 行业协会与上市公司财报
3. 媒体与研究机构（仅作线索，不作证据）

禁止用二手转述的数字直接入表。
