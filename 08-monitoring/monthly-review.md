# 月度跟踪

**所属模块**：08-monitoring
**版本**：v1.2
**最后更新**：2026-11-14

---

## 用途

月度不做判断，只**记录数据、方向与当时的第一反应**。目的是防止「事后回忆偏差」——人在季度末回看时，总会以为自己当时就看出了变化。

记录放在 `reviews/monthly/YYYY-MM.md`，一行一个指标，不写分析。**字段定义、三个日期的区分、修订状态与回测取数规则，统一见 `08-monitoring/data-protocol.md`。**

> V1.1 的月度表只有「维度 / 指标 / 数值 / 方向 / 来源·发布月份」五列。V1.2 起补齐上期值、数据所属期、发布日期、统计口径、修订状态，原因是：只有方向没有口径和时点，两年后无法回测，也无法识别宏观数据被修订造成的假转折。

---

## 格式

```markdown
# YYYY-MM

> 本记录为时点存档，填写后不得回改。勘误写在当期「异常事件」栏。

| 维度 | 指标名称 | 当前值 | 上期值 | 方向 | 数据所属期 | 发布日期 | 数据来源 | 统计口径 | 修订状态 |
|---|---|---|---|---|---|---|---|---|---|
| ① 技术生产率 | 美国 TFP（5 年滚动同比） | | | ↑/→/↓ | YYYY-QN | YYYY-MM-DD | OECD / FRED 序列名 | 实际、季调 | 初值/修正值/终值/已回溯修订/口径变更/未修订 |
| ② 债务与信用 | 美国高收益债 OAS | | | | | | | | |
| ③ 货币与金融 | 10Y TIPS 实际收益率 | | | | | | | | |
| ④ 设备与库存 | 美国产能利用率 | | | | | | | | |
| ⑤a 通胀与资源 | 5y5y 通胀补偿 | | | | | | | | |
| ⑤b 贸易与地缘 | 全球贸易量同比（CPB） | | | | | | | | |
| ⑥ 社会与人口 | 青年失业率 | | | | | | | | |

> ⑥ 为年度指标，月度可留空并在备注写明「年度频率」。
> 方向由「当前值 vs 上期值」复算得出；口径变更时方向填「不可比」。

## 异常事件
- （含：口径变更说明、历史数据回溯修订的原值与新值、突发事件）

## 当时的第一反应（先写下，不要修改）
- （写错也保留。这是后来自查「我到底是看出来的，还是编出来的」的唯一依据。）

## 填表耗时
___ 分钟（若单月超过 40 分钟，应减少指标数量，而不是删字段。）
```

**指标名称必须与 `08-monitoring/indicators.md` 第四节一致**；自定义指标需在当季复盘补进该表，否则以后无法跨期比较。查不到就写「口径缺」「未发布」，不得用二手转述数字补齐。

---

## 修订状态（六选一）

初值 / 修正值 / 终值 / 已回溯修订 / 口径变更 / 未修订。定义见 `08-monitoring/data-protocol.md` 第四节。

**GDP 类指标尤其要标**：美国季度 GDP 有 advance / second / third 三次估计，之后还有年度更新与约五年一次的基准修订。用今天下载的最新序列评价两年前的判断，会产生前视偏差。

---

## 留档规则

- **原始月度文件永久保留，不删除、不覆盖、不回改。**
- 事后发现数值被修订时，在当期记录的「异常事件」栏追加说明，不修改已归档文件。
- 年度只写汇总与索引，见 `08-monitoring/reviews/annual/README.md`。
- 季度复盘引用月度记录时，注明月份与所用版本（初值 / 修订值）。

---

## 数据来源优先级

1. 一手官方及其存档版本（FRED / ALFRED、BEA、BIS、OECD、世界银行、国家统计局、央行、IEA、CPB）
2. 行业协会与上市公司财报（注明报告期与发布日期）
3. 媒体与研究机构（仅作线索，不作证据）

禁止用二手转述的数字直接入表。来源分级见 `09-sources/README.md`。
