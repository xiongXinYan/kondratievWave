# 六维指标体系（康波监测模型设计）

**所属模块**：08-monitoring
**版本**：v1.2（接入数据时点口径与跨层冲突输出）
**最后更新**：2026-11-14

---

## 一、核心结论

本仓库用一个**六维指标体系**替代"康波四阶段"的判断。它的输出不是"现在是春/夏/秋/冬"，而是：

- 哪些维度在改善、哪些在恶化；
- 当前支持哪几条情景假设（见 `04-technology/sixth-wave-hypotheses.md`）；
- 相比上季度，置信度是升还是降。

**权重是研究模型的初始假设，不是经过历史回测验证的权重。** 这一点必须在每次输出中声明。

- 置信度：中（作为框架）；未验证（作为预测工具）。

## 二、支持证据

| # | 证据 | 来源 | 来源性质 |
|---|---|---|---|
| 1 | 历史上每轮转折都伴随"技术 + 债务 + 货币"三者共振 | 历史研究 | 〔学术研究〕 |
| 2 | 单一指标（如 GDP 或股价）无法识别长期转折 | 方法论 | 〔本研究判断〕 |
| 3 | 分维度观察能避免"日本式陷阱"（单一总量指标掩盖结构恶化） | 发展经济学 | 〔学术研究〕 |

## 三、反对证据

| # | 反对证据 | 来源 | 对结论的影响 |
|---|---|---|---|
| 1 | **权重无回测依据**：当前权重是主观设定 | 本研究自省 | 高：必须声明，不得当作验证结论 |
| 2 | 六维之间存在共线（债务与货币、信用与产业） | 计量问题 | 中：加权会重复计算 |
| 3 | 指标阈值随制度变化（如"高债务"的标准在 1980s 与 2020s 不同） | 历史比较 | 高：阈值需滚动校准 |
| 4 | 简单加权分数容易制造虚假精确性 | 方法论 | 高：**因此本仓库不做总分排名** |

| 维度 | 权重（初始） | 观察内容 | 主要数据源 | 频率 | 机制文件 |
|---|---|---|---|---|---|
| **① 技术生产率** | 25% | TFP、劳动生产率、研发强度、专利质量 | OECD、FRED、BLS、世界银行 | 年度 / 季度 | `04-technology/*` |
| **② 债务与信用** | 20% | 三部门杠杆率、信用利差、违约率 | BIS、FRED、央行 | 季度 | `03-macro/debt-cycle.md` |
| **③ 货币与金融** | 15% | 实际利率、货币增速、金融条件指数 | FRED、央行 | 月度 / 季度 | `03-macro/monetary-regime.md` |
| **④ 设备与库存周期** | 15% | CAPEX、产能利用率、库存 | 官方统计、行业协会 | 季度 | `03-macro/capex-cycle.md` |
| **⑤a 通胀与资源** | 10% | 通胀成分、能源与关键矿产价格与库存 | World Bank、IEA、海关 | 月度 | `03-macro/inflation-and-resources.md` |
| **⑤b 贸易与地缘** | 5% | 贸易量、出口管制、军费、储备结构 | CPB、WTO、SIPRI、IMF | 季度 | `03-macro/geopolitics.md` |
| **⑥ 社会与人口** | 10% | 人口结构、就业、收入分配 | 世界银行、国家统计局 | 年度 | `03-macro/demography-and-distribution.md` |

> **v1.1 变更说明**
> 1. 原 ④「产业资本周期」更名为「设备与库存周期」，并明确其主尺是**朱格拉**（7–11 年）、基钦（3–4 年）仅作节奏层。原名称含糊，且未落地 `competing-cycle-theories.md` 中"朱格拉是主力判断层"的裁决。
> 2. 原 ⑤「国际贸易与资源」拆为 ⑤a 与 ⑤b。理由：资源约束是**价格与供给弹性**问题，地缘是**制度动作**问题，两者的判读方向可以完全相反（例如地缘紧张推高资源价格，但抑制总需求）。混在一维会互相抵消。
> 3. 权重总和仍为 100%，仅做拆分，未做增删。
> 4. **每一维必须有机制文件**。这是本次修订的核心约束：没有机制文件的维度，不允许单独赋权。此前 ②③④⑤⑥ 合计 75% 权重处于"有指标无机制"状态。

### 4.1 各维度细分指标（V2 落地清单）

#### ① 技术生产率

| 指标 | 含义 | 判读 |
|---|---|---|
| 美国 TFP 增速（5 年滚动） | 长期生产率 | 趋势性回升 = 新技术兑现 |
| 劳动生产率（每小时产出） | 短期兑现 | 与 TFP 交叉验证 |
| 研发强度（R&D/GDP） | 投入端 | 只作前瞻，不作结论 |
| 专利质量（引用加权） | 创新质量 | 提示未来 5–10 年 |

**注意**：AI 不能只看算力投资（CAPEX），必须看 **投资回报率**（收入/资本、留存、单位产出成本）。这是本仓库的硬性规则。

#### ② 债务与信用

| 指标 | 含义 | 判读 |
|---|---|---|
| 政府 / 企业 / 居民杠杆率 | 债务存量 | 持续上行 = 出清被推迟 |
| 高收益债利差（OAS） | 信用风险定价 | 走阔 = 压力累积；走阔后收敛 = 出清开始 |
| 投机级违约率 | 实际违约 | 上升后回落 = 出清完成 |
| 私人部门信贷 / GDP 缺口（BIS） | 金融周期 | 高于趋势 = 脆弱 |

#### ③ 货币与金融

| 指标 | 含义 | 判读 |
|---|---|---|
| 10 年期实际利率（TIPS） | 资金真实成本 | 长期高位压制估值 |
| 期限利差 | 衰退信号 | 倒挂后 12–24 个月需警惕 |
| 货币增速（M2 等） | 流动性 | 与通胀预期对照 |
| 金融条件指数（NFCI 等） | 综合宽松度 | 紧缩 = 风险资产承压 |

#### ④ 设备与库存周期（朱格拉 / 基钦）

**分层规则**：朱格拉（7–11 年）是主力判断层，基钦（3–4 年）只用于区分"库存调整"与"投资转折"。**任何"周期位置"表述必须写明是哪一层。**

| 指标 | 属于 | 含义 | 判读 |
|---|---|---|---|
| 产能利用率 | 朱格拉 | 供给紧松 | >85% 紧；<75% 过剩 |
| 非国防资本品订单（除飞机） | 朱格拉 | 投资的领先指标 | 连续 2 季负增长 = 转折前兆 |
| 非住宅固定投资 / GDP | 朱格拉 | 投资强度 | 高于历史峰值 = 极端 |
| 设备役龄结构 | 朱格拉 | 更新需求窗口 | 集中老化 = 更新需求将起 |
| 库存 / 销售比 | 基钦 | 库存周期位置 | 被动累库 = 需求转弱 |
| AI 相关 CAPEX / 收入 | 结构变量 | 投资效率 | 比值上升过快 = 过热 |

> **禁止**：用 HP 滤波的实时端点判断"高于/低于趋势"。该做法存在系统性端点偏差，详见 `03-macro/capex-cycle.md` 第三节第 1 条。

#### ⑤a 通胀与资源

| 指标 | 含义 | 判读 |
|---|---|---|
| 5y5y 通胀补偿 | 长期通胀预期 | 脱锚（持续 >3%）= 支持假设 C |
| 单位劳动成本同比 | 成本是否内生化 | 持续高于 CPI = 从成本推动转为螺旋 |
| 能源实际价格中枢（10 年窗口） | 成本约束 | 中枢上移 = 滞胀风险 |
| 铜 / 铝 / 稀土库存天数 | 关键材料供需 | 低库存 + 高需求 = 紧平衡 |
| 关键矿产出口管制事件数 | 制度性供给冲击 | 系统性上升 = 支持假设 D |

> **口径要求**：能源与金属价格必须用**实际价格**（经通胀调整）与**长窗口**，否则结论随基期选择而反转。

#### ⑤b 贸易与地缘

| 指标 | 含义 | 判读 |
|---|---|---|
| 全球贸易量增速（CPB） | 全球化强度 | 长期低于 GDP 增速 = 重构 |
| 出口管制/实体清单新增条目 | 技术脱钩强度 | 年度翻倍 = L1→L2 前兆 |
| 受关税覆盖的贸易额占比 | 壁垒广度 | >30% = 系统性壁垒 |
| 军费 / GDP（主要大国加权） | 安全优先度 | 连续 3 年上升 = 支持假设 D |
| 储备货币份额（IMF COFER） | 货币体系分散度 | 美元年均降 >1pp = 分散加速 |
| 跨境资本管制新增国别数 | 资本流动限制 | 多国同时收紧 = L2 信号 |

> **注意**：地缘维度不产出交易信号，只产出**风险敞口**判断。分级定义见 `03-macro/geopolitics.md` 第 4.2 节（L0–L3）。

#### ⑥ 社会与人口

| 指标 | 含义 | 判读 |
|---|---|---|
| 主要经济体总和生育率 | 长期分母 | 持续低于 1.5 = 结构性压力 |
| 劳动年龄人口占比 | 供给端 | 下降 = 潜在增速下移 |
| 青年失业率 | 社会张力 | 高企 = 分配矛盾 |
| 收入前 10% / 后 50% 份额比 | 分配 | 恶化 = 政策转向压力 |

## 五、历史案例

- **教训**：1970s 有学者用"周期位置"判断，预测 1980s 大萧条，实际是滞胀后的长繁荣。若当时用六维分维度观察，"生产率仍在、债务不高"的信号本可避免这种误判。
- **启示**：**分维度看，比看总分可靠。**

```
【季度宏观速览 · YYYY-Q?】

① 技术生产率   {改善/持平/恶化}  依据：{…}
② 债务与信用   {…}              依据：{…}
③ 货币与金融   {…}              依据：{…}
④ 设备与库存   {…}              依据：{…}
⑤a 通胀与资源  {…}              依据：{…}
⑤b 贸易与地缘  {…}              依据：{…}
⑥ 社会与人口   {…}              依据：{…}

周期位置（必须指明尺度）：
  朱格拉：{扩张后段 / 收缩 / 复苏}
  基钦：  {补库 / 去库}
  （康波不参与定位，只作技术生命周期背景）

跨层冲突（四层方向相反时不得择一叙述，见 03-macro/cycle-nesting.md）：
  {无 / 组合①~④ / 未归类}
  向上层与依据：{…}  向下层与依据：{…}
  已持续：{N} 季  裁决状态：{未裁决 / 已裁决}

本季支持的情景：{A / B / C / D}
本季反对的情景：{…}
关键变化（Top 3）：
  1. …
置信度变化：{升/降/不变}，原因：{…}
下季度重点观察：{…}
```

**禁止输出**：
- "当前处于康波萧条期第 X 年"
- 单一总分（如"康波指数 47 分"）
- 任何指向具体年份的"拐点预测"

## 七、未来观察指标

| 指标 | 当前值 | 变化方向 | 触发阈值 | 意味着什么 |
|---|---|---|---|---|
| 六维体系是否经回测验证 | 未验证 | — | 历史回测显著优于单指标 | 可提升为正式识别方法 |

## 八、结论失效条件

1. 若六维体系经历史回测证明**无预测力** → 降级为"观察清单"，不再声称有识别能力。
2. 若某维度长期无数据或数据质量差 → 该维度权重应下调，并记录原因。**下调后必须相应上调其他维度，保持总和 100%；不得只下调不重分配。**
3. 若出现更简洁有效的替代框架 → 整体替换。
4. **若某一维的机制文件缺失或被推翻 → 该维权重置零**，不得以"指标还在"为由保留。这是 v1.1 新增的硬约束：权重必须挂在机制上，不能挂在数据可得性上。
5. 若 ⑤a/⑤b 的拆分被证明无必要（两者判读方向高度一致）→ 合并回单一维度，并记录原因。
