## 使用原则

1. **一手优先**：档案、官方统计、原始论文 > 综述 > 媒体。
2. **每个数字必须能回溯到这里的某个条目**。回溯不到的数字，不进正文。
3. **标注分歧**：若某数字存在公认分歧，必须在此列出两派，不得只取一派。

## 一、数据源

| 来源 | 覆盖 | 接口/获取方式 | 用途 |
|---|---|---|---|
| **FRED**（圣路易斯联储） | 美国宏观、利率、信用利差 | API（免费 key） | 六维 ②③④ |
| **BIS** | 全球信贷、金融周期、杠杆率 | 数据门户 / CSV | 六维 ②③ |
| **OECD** | 生产率、经济展望、就业 | API / SDMX | 六维 ①⑥ |
| **IMF** | WEO、国际收支、债务 | API / 数据下载 | 六维 ②⑤ |
| **World Bank** | 全球发展、人口、产业 | API | 六维 ⑤⑥ |
| **国家统计局** | 中国宏观 | 网页 / 数据接口 | 中国场景 |
| **CPB** | 全球贸易量 | 月度更新 | 六维 ⑤ |
| **IEA** | 能源供需与电力 | 报告 / 数据 | 六维 ⑤ |
| **WHO** | 公共卫生事件 | 数据门户 | 事件类参数 |
