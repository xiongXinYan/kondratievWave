# Kondratiev Wave

## 长期经济周期与个人战略研究系统

研究长期经济周期、技术革命、全球产业变迁及资产价格之间的关系，探索未来 5～10 年的职业发展、资产配置和风险管理策略。

**V1.1 · 机制层补齐与复盘流程实跑**

---

## 这是什么，不是什么

| 是 | 不是 |
|---|---|
| 一个持续更新证据、修正判断的研究框架 | 一个康波知识库 |
| 研究"未来经济和产业可能往哪走" | 预测下一轮康波的具体拐点年份 |
| 情景分析 + 观察条件 + 失效条件 | 春夏秋冬的择时信号 |
| 与 `investment` 仓库分工的研究层 | 交易策略与仓位管理系统 |

**核心原则**

- 不迷信周期
- 不预测精确拐点
- 不把历史相关性当成因果关系
- 用数据验证宏观判断
- 用情景分析管理未来不确定性
- 用实际行动获得长期收益

---

## 三个问题三层分工

| 层次 | 回答什么 | 归属 |
|---|---|---|
| **康波研究** | 未来经济和产业可能往哪里发展？ | 本仓库 |
| **投资策略** | 什么资产值得配置？什么时候买？配置多少？ | `investment` 仓库 |
| **风险管理** | 如果宏观判断错误，如何控制损失？ | `investment` 仓库的风险约束层 |

本仓库只输出**方向、条件与证据**，不输出**仓位、买点与杠杆倍数**。

## 每份研究文件的统一格式

所有研究结论使用 `templates/research-template.md`，必含两个字段：

- **反对证据**：能推翻本文结论的事实
- **结论失效条件**：出现什么情况，本文判断就应作废

这两个字段不是装饰。它们的目的是防止整个项目逐渐变成一个只收集支持自己观点的信息库。

## 工作流：这套东西怎么用

文档写得再好，不跑就等于零。本仓库的运行节奏如下，**总耗时约每月 20 分钟 + 每季 90 分钟**。

### 每月（20 分钟）

1. 复制 `08-monitoring/reviews/monthly/2026-11.md` 改名为当月，填 6 行数字。
2. 只记录方向和异常事件，**不写分析**。
3. 在手记里写下"当时的第一反应"，不要修改。这一栏是后来自查"我到底是看出来的，还是编出来的"的唯一依据。

> 若某指标查不到月度数据，标「口径缺」，不要勉强填。这本身就是对指标体系的反馈。

### 每季（90 分钟）

1. 复制 `08-monitoring/reviews/2026-Q4.md` 改名为当季。
2. 填六维变化 + 情景判断（**不给概率**）。
3. **对照 `08-monitoring/assumptions-ledger.md` 逐行更新状态**——不得跳行，不更新等于默认成立。
4. 检查是否有条目变为「已推翻」，若有，同时改来源文件并记 CHANGELOG。
5. 自评流程：哪一步做不下去，改流程，不要跳过。

### 每年（半天）

1. 复核结构变量（人口、分配）与所有「年度」频率条目。
2. 审慎评估是否调整六维权重。**权重调整必须同时更新 `indicators.md` 第八节并记 CHANGELOG。**
3. 把 30 天前的月度记录按主题归并，删除原始文件。

### 何时重写整份文件

只看一个信号：**该文件的「结论失效条件」被触发**。情绪、新闻、市场波动都不是重写的理由。

## 分期原则：不只有一套年份

康波理论在学术上仍有争议。本仓库对每一轮分期都给四层：

1. **主流分期**（范·杜因 / 通行教材）
2. **不同学者的分期**（康德拉季耶夫本人、熊彼特、佩蕾丝、国内研究者等）
3. **本研究判断**（本仓库采用的口径）
4. **依据与置信度**（为什么这么定，以及在多大程度上可信）

这样出现新证据时，只需修订第四层，不必推翻整篇。

---

## 归因原则：区分"同期"与"因果"

历史上发生在萧条期的战争、饥荒、瘟疫，**不能一概视为康波出清的结果**。

本仓库对每个历史事件标注归因等级：

| 等级 | 含义 |
|---|---|
| **A** | 康波可解释：事件的主要驱动来自技术与资本周期 |
| **B** | 部分相关：宏观周期是背景条件之一，但不是直接原因 |
| **C** | 不可归因：主因是制度、宗教、民族、气候或偶发政治事件 |

只在 A 级事件上讨论"出清方式"，B 级作为背景，C 级不作为康波证据使用。
