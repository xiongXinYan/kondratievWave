# 关键材料与资源约束

**所属模块**：04-technology
**版本**：v0.1
**最后更新**：2026-11-09

## 一、核心结论

每一轮技术革命都有**物质基础**：蒸汽靠煤、铁路靠铁、电力靠铜、汽车靠石油、信息靠硅。第六轮的物质基础很可能是 **铜 + 铝 + 稀土 + 锂 + 银 + 铀**——它们共同服务于"电—算—储—驱"这条链。

与前面几轮不同的是：**这一轮的资源约束来得更物理、更硬**。铜矿品位下降、新矿投产周期 10–15 年、稀土与关键矿产的加工高度集中于少数国家。这不只是经济问题，也是地缘问题。

- 结论：关键材料是第六轮"确定性较高但周期性极强"的环节。
- 置信度：中高（长期需求）；中（短期价格）。

| # | 反对证据 | 来源 | 对结论的影响 |

| 1 | **商品价格由库存与边际成本决定，而非长期叙事** | 商品经济学 | 核心反证：长期逻辑不能替代周期判断 |

| 5 | 回收与城市矿业比重上升 | 产业趋势 | 削弱：长期供给约束 |

## 五、历史案例

**类比：石油（1900–1970）与铜（2003–2011）**

- **相似**：技术革命催生新增需求 → 产能响应滞后 → 价格上涨 → 资本开支扩张 → 若干年后过剩 → 价格崩塌。
- **不相似**：本轮叠加了**地缘与出口管制**因素，价格可能更偏离基本面。
- **启示**：**长期方向与短期价格是两件事**。判断"铜是未来十年重要资源"，和"现在该不该买铜矿股"，是两个完全不同的问题。

## 六、当前判断

- 长期：电—算—储—驱链条对铜、铝、稀土的需求结构是真实且长期的。
- 短期：价格高度依赖库存、矿端供给扰动与政策，**不具备"只涨不跌"的属性**。
- 研究重点不是"会不会涨"，而是：**当前处于供给周期的哪个位置、库存处于什么水平、资本开支是否已启动**。

## 八、结论失效条件

1. 若替代材料（如铝代铜、超导、钠离子）出现规模化突破 → 长期需求假设需重估。
2. 若回收体系大幅提升供给占比 → 供给约束假设需下调。
3. 若矿业资本开支在 2 年内大幅扩张 → 需提前预警 3–5 年后的过剩。
