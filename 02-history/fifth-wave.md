# 第五轮：信息与全球化（约 1982–2025）

**所属模块**：02-history
**版本**：v0.2（重构版）
**最后更新**：2026-11-09

## 一、核心结论

第五轮的关键特征不是"信息革命"，而是**"没有完成出清"**。

- 2001 泡沫破裂是预警，2008 全球金融危机是转折；
- 此后本应出现的产能与债务出清，被**量化宽松 + 财政赤字货币化 + 零/负利率 + 产业补贴**系统性地推迟；
- 结果是：**账面没有崩塌，但代价换了形态**——低增长、资产价格与实体脱钩、贫富分化、生育率崩塌、债务转移给未来。

- 结论：第五轮是本仓库记录的第一轮**"柔性出清"**。人口代价以公共卫生事件的形式集中兑现（COVID-19），但其深层代价是**代际转移**，目前无法量化。
- 置信度：中（分期分歧大，"是否已经结束"无共识）。

## 八、当前判断

对当下的启示（限定使用）：

1. **柔性出清的代价最容易被低估**，因为它不表现为崩溃，而表现为"慢慢变差"——低增长、买不起房、不生孩子、年轻人对未来预期下降。
2. 评估本轮是否结束，不应看"经济是否崩溃"，而应看：**债务是否被真实消化、生产率是否真实回升、分配矛盾是否被处理**。
3. 这三者目前（2026）都未完成。因此本仓库将"第五轮是否结束"标记为**未决**，不使用"我们已经在第六轮"这类断言。

## 十、结论失效条件

1. 若 2026–2030 出现生产率趋势性回升 + 债务率下降 + 实际工资回升 → 可判定第五轮已结束，第六轮已启动。
2. 若出现新一轮系统性金融危机（非局部）→ 说明柔性出清失败，转为硬出清，本文件需重写。
3. 若学界对分期达成新共识（如起点改为 1991）→ 分期表需修订。
