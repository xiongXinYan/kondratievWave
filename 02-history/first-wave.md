# 第一轮：蒸汽与纺织（约 1780–1845）

**所属模块**：02-history
**版本**：v0.2（重构版）
**最后更新**：2026-11-09

---

## 一、核心结论

第一轮康波的核心不是"蒸汽机发明"，而是**动力从"地点绑定"（河流）变成"地点自由"**，从而使工厂可以集中在城市、劳动力可以从不流动变成流动、资本可以从商人资本转向工业资本。它的萧条期（约 1825–1845）**没有产生大规模战争**，代价主要通过两种方式外移：**殖民地的粮食与人口，以及本土工人阶级的贫困化**。

- 结论：本轮出清方式为"通胀性外移 + 阶级性贫困"，人口损失主要在殖民地与爱尔兰，主因果链不在本土。
- 置信度：中。

| # | 证据 | 来源 | 来源性质 |

| 3 | 1832 年改革法案、1838 年起宪章运动、1840s "饥饿的四十年代" | 英国政治史 | 〔通行综述〕 |
| 4 | 爱尔兰大饥荒（1845–1852）人口锐减，百万级死亡、百万级外逃 | 爱尔兰人口史 | 〔学术研究，死亡数区间 50 万–150 万，学界分歧大〕 |

## 五、五字段分析

| 字段 | 内容 |
|---|---|
| **技术革命** | 蒸汽机规模化（瓦特改良后）、棉纺织机械化（珍妮机、水力纺纱机、走锭纺纱机）、炼铁技术改良（焦炭炼铁、搅炼法）、运河网 |
| **资本周期** | 商人资本 + 早期工业资本；运河与纺织厂是主要投资方向；1825 年运河与南美债券投机引发危机；资本回报率在 1830s–40s 承压后转向铁路 |
| **货币金融** | 金本位（1816 年英国立法、1821 年恢复兑换）、英格兰银行体系、银行券危机（1825、1836、1839、1847）；通货紧缩压力明显 |
| **地缘政治** | 拿破仑战争（1803–1815）后的秩序重建；维也纳体系；英国海权与殖民地扩张；1840 年鸦片战争打开中国市场 |
| **社会分配** | 技术红利主要流向工厂主与地主；工人实际工资长期停滞；《济贫法》修正案（1834）强化劳动纪律；宪章运动 |

## 六、分期四层

| 层次 | 内容 |
|---|---|
| **主流分期** | 1782–1845（回升 1782–1802 / 繁荣 1802–1825 / 衰退 1825–1836 / 萧条 1836–1845） |
| **异见分期** | 康德拉季耶夫本人以价格序列为准，起点约 1780s–1790s；部分学者以 1815 年拿破仑战争为转折点；也有以 1790–1848 为一段的口径 |
| **本研究采用** | 约 1780–1845，转折点取 **1825 年英国生产过剩危机**，而非 1815 年 |
| **依据与置信度** | 依据：1825 年是首次"机器产能超过有效需求"的危机，1815 年更多是战后需求回落。置信度：**中低**（各流派分歧 5–10 年） |

## 七、事件归因等级

| 事件 | 时间 | 归因等级 | 理由 |
|---|---|---|---|
| 1825 年英国生产过剩危机 | 1825 | **A** | 直接源于纺织产能扩张与信贷紧缩，符合技术-资本周期逻辑 |
| 1837 年恐慌 | 1837 | **A（偏 B）** | 与运河/土地投机和 1836 年银行券紧缩相关，但也有美国地方银行制度因素 |
| 宪章运动 | 1838–1848 | **B** | 是分配矛盾的政治表达，宏观周期是背景而非主因 |
| 爱尔兰大饥荒 | 1845–1852 | **B（原判 A，已下调）** | 直接触发是晚疫病；放大机制是佃农制与粮食出口政策，非资本周期 |
| 印度 19 世纪饥荒 | 多次 | **C** | 主因是殖民税制与粮食商品化，制度性因果强于周期因果 |
| 1840 年鸦片战争 | 1840 | **C** | 主因是贸易逆差与殖民战略，与康波无直接关系 |

## 八、当前判断

对当下的启示（限定使用）：

- 第一轮的经验适用于**"本土需求不足 + 向外寻找市场"**的结构，而非"必然发生战争"。
- **技术红利分配不均是常态，不是例外**；萧条期的社会冲突，往往先于经济崩溃出现。
- 这一轮的人口代价主要发生在**制度扭曲的边缘地带**，而非危机爆发地。这一点在评估当代风险时值得注意：**风险常在最薄弱环节兑现**。
